# 减肥食谱（今日减脂）

每日减脂食谱 H5，长得像微信小程序。先填身高体重年龄性别，按 Mifflin-St Jeor 算基础代谢，再从家常菜库里排出今天的早午晚加餐。不同身材会看到不同的菜，不是改个数字的固定周菜单。

## 本地运行

需要 Node.js 18 或以上。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的本地地址即可。手机全屏，电脑上是居中手机框。

## 打包成静态站点

```bash
npm run build
```

产物在 `dist/`。纯静态，没有后端、没有登录、没有接口密钥。

```bash
npm run preview
```

## 部署到腾讯云开发静态托管

Vite 写了 `base: "./"`，可挂在子目录。建议路径：

```
/jianfei/
```

把 `dist/` 上传到该目录后打开：

```
https://你的云开发域名/jianfei/
```

路由走 hash，刷新详情页不用服务器重写。

## 功能

- **身体数据**：身高 cm、体重 kg、性别、年龄、减脂/维持。减脂大约少 450 千卡，女不低于 1200、男不低于 1500。蛋白质按 1.6g/kg（界面最多显示 120g）
- **今天**：按你的目标画圆环；每道菜都标千卡、蛋白质、碳水、脂肪；可「吃完了」、记体重（斤）、看连续天数
- **本周**：7 天各自按「身材 + 日期」生成，不是罐头周一到周日
- **筛选**：全部 / 快手 / 高蛋白 / 低卡
- **采购**：重复食材按克数加总，调味单独一组
- **换一道**：只推荐还吃得进当天剩余热量的同餐菜

数据在 `localStorage`。换手机或清缓存要重新填身材。

## 技术

Vite + React + TypeScript。食谱和营养估算都在前端。
