# 减肥食谱（今日减脂）

每日减脂食谱 H5，长得像微信小程序：今天吃什么、一周循环、采购清单、做法步骤都在里面。食材都是菜市场常见的，今晚就能做。

目标大约 **1400–1600 千卡 / 天**，蛋白质大约 **90–110 克**，一人份。

## 本地运行

需要 Node.js 18 或以上。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的本地地址即可。手机和电脑都能看，电脑上会居中成一个手机框。

## 打包成静态站点

```bash
npm run build
```

产物在 `dist/`。这是纯静态站点，没有后端、没有登录、没有接口密钥。

本地预览打包结果：

```bash
npm run preview
```

## 部署到腾讯云开发静态托管

本仓库的 Vite 配置写了 `base: "./"`，相对路径引用资源，可以挂在子目录下。

建议站点路径：

```
/jianfei/
```

把 `dist/` 里的文件上传到该目录。用浏览器打开：

```
https://你的云开发域名/jianfei/
```

刷新食谱详情页也没问题：页面路由走 hash（`#/today`、`#/recipe/...`），不依赖服务器重写。

## 功能

- **今天**：日期、全天热量和蛋白质，早午晚加餐四张大卡片
- **本周**：周一到周日固定循环，点一天看当天菜，当天会高亮
- **采购**：默认合并「今天」的食材，可切换「这一周」；勾选会记在本地
- **食谱详情**：热量、蛋白质 / 碳水 / 脂肪、一人份、用量、分步做法、一句减脂小技巧
- **换一道**：同一餐型从食谱库里换一道，按日期记在本地，刷新还在

数据都存在浏览器的 `localStorage`，换手机或清缓存会回到默认一周菜单。

## 技术

Vite + React + TypeScript。没有接口，食谱和营养估算都写在前端。
